# Inverse pendulum

Inverted pendulum built from printed parts and cheap electronics to test classical loop control against reinforcement learning approach.

## Results
PID velocity control:
[*video of the pendulum balancing*](https://youtube.com/shorts/lt8KjExcmE4?feature=share)

PID double loop torque control:
[*video of PID double loop control](https://youtube.com/shorts/xpPwe5tMBqU?feature=share)

Neural network control with reinforcement learning:
[*video of neural network control](https://youtube.com/shorts/eyTFQ6OgbI4?feature=share)



## Electronics used

* ESP 32 devkit
* SimpleFOC mini
* AS5600 Magnetic Encoder
* Brusheles DC motor MiToot 2206/100T

# Simple inverse pendulum

Simple inverse pendulum using 3d printed parts and cheap electronics.

## Electronics used

* ESP 32 devkit
* SimpleFOC mini
* AS5600 Magnetic Encoder
* Brusheles DC motor MiToot 2206/100T
